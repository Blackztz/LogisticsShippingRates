# LogisticsShippingRates

Repositorio para la gestión y cálculo de tarifas de logística y envíos de la organización.

## Código de Conducta (Code of Conduct)

Nos comprometemos a proporcionar un entorno acogedor, inclusivo y seguro para todos los colaboradores.

1. **Sé respetuoso:** Respeta los diferentes puntos de vista y experiencias.
2. **Sé constructivo:** Ofrece comentarios constructivos y acepta las críticas con profesionalismo.
3. **Sé profesional:** Mantén una conducta profesional en todas las comunicaciones y interacciones del proyecto.

---

## Guías de Contribución (Contribution Guidelines)

¡Las contribuciones son bienvenidas! Para colaborar en este proyecto, sigue estos pasos:

1. **Crear una rama:** Crea una nueva rama a partir de main para tu función o corrección.
2. **Realizar cambios:** Mantén los commits limpios, concisos y bien documentados.
3. **Enviar un Pull Request:** Abre un Pull Request (PR) describiendo tus cambios.
4. **Revisión de código:** Espera la revisión antes de fusionar (*merge*) los cambios en main.
